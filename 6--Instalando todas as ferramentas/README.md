## Conteúdos aprendidos 

Ele ensina a instalar as ferramentas, sendo o navegador o google chrome e o editor de código sendo o visual studio code.
    Ao instalar o google chrome ele recomenda instalar do site oficial para evitar problemas futuros e a aceitar as predições do aplicativo, entretanto ele explica que não é bom fazer isso para qualquer aplicativo.

    Para instalar o visual studio code é só baixar o aplicativo pelo site da microsoft que é in Cold.Visualstudio.com, ao instalar tem duas versões, a estável e a insyderz, a versão estável(stable) é uma versão que dá menos problema, enquanto a insyderz tem recursos novos, é mais rápida, mas fatalmente vai dar alguns problemas.
Para windows é recomendado a versão estável(stable), nas configurações ele recomenda colocar as linguagens JS e PHP.

Ao decorrer do vídeo ele ensina a fazer algumas configurações básicas como colocar em português, a quebra de linha grande na hora de programar, o aumento dos caracteres na tela de comendo, escolha de claro ou escuro e como salvar automaticamente.
