## Conteúdos aprendidos 


  o computador não tem inteligência própria, acrescentamos dados a ele o qual funciona com sinais. Os dados são representados com dados binários que são representados por 1 e 0 e são chamados de bit, e a cada 8 bits se torna um byte.
Os sinais são representados com o 0 e com o 1, o qual o 0 funcionaria como estando sem sinal e o 1 com sinal, o qual são chamados de binário ou bit, eles servem para qualquer aparelho eletrônico. Para representação de dados se utiliza 8 bits o equivalente a um octeto, e a cada um octeto se tem um byte// ondas binarias ou ondas quadradas.
A cada 8 bits se tem 1 byte // a cada 1024 bytes se tem 1 KB; a cada 1024 KB se tem 1 MB; a cada 1024 MB se tem 1 Gb; a cada 1024 gb se tem 1 TB; a cada 1024 tb se tem 1 pb; a cada 1024 PB se tem 1 EB; a cada 1024 EB se tem 1 Zb; e a cada 1024 zb se tem 1 yb
A primeira e a segunda letra maiúscula representa que é um conjunto de bytes , exemplo: MB mega bytes
Enquanto apenas a primeira letra maiúscula representa um conjunto de bits,
exemplo: Mb megabits // normalmente utilizamos as duas letras maiúsculas para representar armazenamento, enquanto a de apenas uma letra maiúscula para representar a transmissão. 
Nos conectamos a internet por meio de um dispositivo o qual é chamado de cliente e para se conectar utilizamos o modem  e outro aparelho como referência para nos conectar a internet, mas tem  o problema que os aparelhos entendem redes diferentes, por exemplo o computador entender em /__/__/ enquanto o telefone entende em ~~~~  e para isso o modem traduz as ondas de cada aparelho, chamado de modulação e quando o contrário é demodulação; sendo essa a funcionalidade de um modem.
Acessamos um serviço por meio de um servidor, o qual tem seu ip e o usuário tem outro, mas para pesquisar colocamos apenas o nome, pois existe o servidor DNS = sistema de nome de domínio é como se fosse uma agenda que associa o nome do site com o ip. Um exemplo é que quando desejamos entrar no youtube(serviço) não colocamos seu ip e sim apenas seu nome, então o DPS identifica o nome em sua agenda e o associa ao site, sendo assim possível ter acesso ao servidor.
A internet é finita e tem redes finitas , o qual o roteamento pode seguir diversos caminhos que seguem diferentes rotas, ocasionando por exemplo a maior velocidade ao pesquisar algo ou a sua demora ao pesquisar a mesma coisa, por diversos motivos a rede pode mudar de caminho como uma rede que não está funcionando, está congestionada, bloqueada e diversos outros motivos .
