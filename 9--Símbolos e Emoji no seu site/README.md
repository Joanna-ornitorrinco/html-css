## Conteúdos aprendidos

Para pular mais parágrafos não utilize <br><br><br><br><br> faça essa modificação pelo CSS, devido essas sequência de <br> serem uma poluição visual e não utilizada por programadores profissionais.

Para colocar um comentário que não aparecerá no site utilize <!-- –> 
e tudo que for colocado aí dentro não aparecerá no resultado final 

&lt; significa Less Than, enquanto &gt; significa Greater Than 

    Alguns símbolos especiais e como colocá los no seu site:
&reg; que significa Marca registrada 
&copy; que significa Copyright
&trade;  que significa marca comercial
&euro;  que significa euro
&pound;  que significa libra
&yen;  que significa yen
&cent;  que significa centavos
&Delta;  que significa delta
&uarr;  que significa seta para cima  


    Para adicionar emojis 
Para adicionar emojis é necessário pesquisar por Emojipedia(https://emojipedia.org/pt)  e buscar pelo seu emoji desejado, em alguns navegadores é possível copiar a imagem disponibilizada no site dos emojis, entretanto também é disponibilizado o código, para que seja possível todos utilizarem emojis.
Para adicionar um emoji é necessário antes de colocar o código do emoji acrescentar &#x
Um exemplo é:
&#x1F499 que representa 💙
