## Conteúdos aprendidos 

Site estático: é quando o mesmo site é entregue para vários clientes
 
    HTML, CSS,JS é dito que vão funcionar ao lado do cliente, sendo chamados como client-side ou tecnologias para o lado do cliente o qual funciona através do  navegador (como google chrome,Mozilla Firefox,Microsoft Edge, etc). Nesse sistema o papel do servidor é apenas entregar o arquivo para o cliente. 
Um exemplo: o servidor é o supermercado vendendo comida, o HTML,CSS e JS são os alimentos para fazer misto como queijo, presunto, pão e manteiga e o navegador é a misteira, a qual possibilita a utilização dos alimentos disponíveis para fazer o misto.

    Front-end significa que desenvolve um trabalho com o client-side, ou seja, desenvolve em HTML, CSS e JS, entretanto para ser um desenvolvedor front-end é necessário ter um breve conhecimento em imagens, saber o básico de cores, tipografia, photoshop, contudo é importante ressaltar que um desenvolvedor front-end não é um designer, os itens citados acima são necessários ter apenas um conhecimento prévio, pois o designer fará o modelo do site e o desenvolvedor front-end terá que acrescentar o HTML e JS sendo necessário às vezes breves modificações no CSS.
As características dos desenvolvedores de front-end são especializadas em client-side e em gerar parte visual e interativa do site, priorizam a boa experiência e interatividade para o usuário e trabalham com designers.
Designer e desenvolvedor front-end não são a mesma coisa!

Os programas que são do servidor são chamados de server-side, são outro conjunto de ferramentas e outro conjunto de linguagem, o qual os desenvolvedores são chamados de back-end 

Back-end tem mais foco na interação do código com o servidor, as linguagens do back-end são PHP, JS o qual tem uma versão diferente para server-side e client-side, C sharpe, Python, Ruby e Java.

Full-stack é o desenvolvedor que é um desenvolvedor em front-end(client side) e back-end(server side)
